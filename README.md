TrueClean is a full-stack platform that lets users easily **book home cleaning services**, while admins can manage all booking requests — confirm, cancel, or keep them pending. Built for both usability and performance, it features smooth animations, secure login, and real-time status updates.

---
## 🎯 Key Features

### For Users  
- Secure JWT-based authentication  
- Book home cleaning services  
- Track bookings in **My Bookings** dashboard  
- Real-time updates on booking status  
- Smooth, animated transitions (Framer Motion)  

### For Admins  
- View and manage all booking requests  
- Confirm, cancel, or mark as pending  
- Dashboard to see everything at a glance  
- Protected admin-only routes  

---

## 🛠️ Tech Stack

**Frontend:**  
- Next.js  
- Tailwind CSS  
- Framer Motion  

**Backend:**  
- MongoDB + Mongoose  
- JWT for authentication  
- Bcrypt for password hashing
